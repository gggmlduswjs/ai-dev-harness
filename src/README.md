# src/ — 제품 코드

```text
src/
├── backend/     서버 코드 — 도메인(업무)별 폴더
└── frontend/    화면 코드
```

언어와 프레임워크는 프로젝트가 정합니다. 이 틀은 **폴더의 역할과 이름 규칙**만 정합니다(`docs/CONVENTIONS.md` 4장).

## 이 구조가 맞는 프로젝트

**웹서비스(서버 + 화면)** 기준입니다. 다른 종류는 이렇게 바꿉니다.

| 프로젝트 | 구조 |
|---|---|
| 서버만 있는 API | `src/backend/`만 사용 (`frontend/` 제거) |
| 라이브러리 · CLI 도구 | `src/<패키지명>/` 하나로 시작하고 **업무(도메인) 단위로 나누는 원칙**만 적용 |
| 데이터 파이프라인 · 배치 | `src/<단계 또는 업무>/` 단위 폴더, `scripts/`에 실행 진입점 |
| 모바일·데스크톱 앱 | 해당 프레임워크의 표준 구조를 쓰고, `docs/`·`templates/` 체계만 적용 |

바뀌지 않는 것: 도메인 단위 폴더, 역할 이름 통일, 루트에는 읽을 것만([CONVENTIONS](../docs/CONVENTIONS.md) 4장).

# .dev/plans/ — 구현 계획서

복잡하거나 위험한 작업에만 만듭니다. **superpowers `writing-plans` 스킬이 계획서를 이 폴더에 저장합니다**(형식은 스킬이 정하므로 별도 양식 파일이 없습니다). 저장 위치 설정은 [`CLAUDE.md`](../../CLAUDE.md)의 「superpowers 저장 위치」를 봅니다.

- 파일명: `YYYY-MM-DD-기능명.md`
- 기본 분업에서는 Claude, Codex 단독에서는 Codex가 작성하고, 필요한 계획 승인을 받은 뒤 구현합니다.
- 기존 계획에 **`Codex 인수인계` 절**을 포함합니다. 필수 내용과 실행 방법은 [일상 가이드](../../docs/guides/2-daily-loop-and-second-brain.md#작업-절차)가 정본입니다. 승인된 계획을 별도 실행기·새 계획서로 다시 번역하지 않습니다.
- 작업이 끝나면 `status: Historical`로 바꾸고, 앞으로도 유효한 내용은 `docs/`에 옮깁니다.

# 결정 기록

정한 것과 그 까닭을 번호 순서로 적는다. **덧붙이기만 하고 지우지 않는다.** 결정을 바꾸면 원래 항목 밑에 날짜와 함께 인용으로 덧붙이고, 새 번호로 바뀐 결정을 적는다.

```markdown
### N. {결정 한 줄}
{YYYY-MM-DD} · {무엇을 골랐나} · {왜} · {포기한 것}

> {YYYY-MM-DD} 바뀜 — M 을 본다.
```

## 정한 것

### 1. {예: 할 일은 GitHub Issues 한 곳에서 관리한다}
{YYYY-MM-DD} · 진행 상태를 문서 · 보드 두 곳에 두면 어긋난다. 이슈 · PR · CI 가 같은 증거를 남긴다. 포기한 것: 별도 프로젝트 관리 도구의 일정 뷰.

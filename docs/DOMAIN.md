# 업무 규칙

화면과 상관없는 업무의 진실. **표 한 줄 = 테스트 하나.** 규칙을 바꾸면 테스트를 같이 바꾼다. 규칙 ID 는 테스트 이름이나 주석에 그대로 쓴다.

## 용어

같은 것을 다른 이름으로 부르지 않는다. 코드 이름도 여기서 고정한다.

| 용어 | 코드 이름 | 뜻 | 헷갈리기 쉬운 말 |
|---|---|---|---|
| {예: 주문} | `Order` | 고객이 결제한 한 건. 상품 여러 줄을 가진다 | 발주(우리가 공급처에 하는 주문)와 다르다 |

## 데이터 단위

화면 · API 가 주고받는 단위. 필드는 코드(타입 · 스키마)가 정본이고, 여기에는 단위와 식별 규칙만 둔다.

| 단위 | 식별자 | 누가 만든다 | 누가 바꾼다 | 코드 위치 |
|---|---|---|---|---|
| | | | | |

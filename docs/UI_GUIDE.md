# UI 가이드

> UI 키트(Tabler · shadcn 등)를 쓰면 **키트가 정해 주지 않는 것만** 적는다. 클래스 · 부품 모양은 키트 문서에서 복사하고 여기에 옮겨 적지 않는다.

- UI 키트: {이름 · 버전 · 문서 주소} · 우리 값: {토큰 파일 경로}

## 1. 원칙

1. {예: 업무 도구처럼 — 꾸밈보다 읽기 · 찾기 · 입력이 빠른 게 먼저}
2. 한 화면엔 한 가지 일. 주 행동 버튼은 하나.
3. 숫자는 오른쪽, 글자는 왼쪽 정렬.
4. 부작용 있는 행동(발송 · 삭제 · 확정)은 대상과 건수를 보여 주고 한 번 더 묻는다.

## 2. 하지 마라

| 금지 | 대신 |
|---|---|
| 키트에 있는 부품을 다시 만들기 | 키트 클래스 · 부품 |
| 화면마다 전용 CSS · 다른 너비 · 다른 여백 | 키트 유틸리티 · 레이아웃 틀 하나 |
| 토큰 밖 색 · 인라인 색칠 | 키트 색 · 토큰 |
| 유리 효과 · 글자 그라데이션 · 네온 · 블러 배경 | 평평한 카드 |
| 아이콘을 둥근 색 상자로 감싸기 · 「AI」 장식 배지 | 아이콘만 · 업무 이름 그대로 |

## 3. 색

| 키트 변수 | 우리 값 | 쓰는 곳 |
|---|---|---|
| {primary} | {토큰} | 주 버튼 · 링크 |

## 4. 부품 — 키트에 없어서 우리가 가진 것만

| 부품 | 쓰는 곳 | 코드 위치 |
|---|---|---|
| | | |

새 부품은 같은 모양이 두 화면 이상 나올 때만 만든다.

## 5. 레이아웃 — 화면 종류마다 본뜰 견본

| 화면 종류 | 견본(키트 예시 페이지) | 고정할 것 |
|---|---|---|
| 목록 | | {검색 위치 · 행 누르면 무엇} |
| 입력 폼 | | {라벨 위치 · 저장 버튼 위치} |
| 상세 | | {행동 버튼 위치} |

모든 화면의 상태 5개: 데이터 없음(이유 + 다음 행동) · 불러오는 중 · 실패(다시 시도) · 권한 없음 · **미측정(0 으로 보이지 않기)**.

# 디자인시스템

화면 디테일의 대부분은 여기서 나온다. 화면마다 모양을 정하지 않고, **토큰과 패턴이 한 번 정한 것을 모든 화면이 물려받는다.** 값과 부품의 정본은 코드다 — 이 문서는 위치와 규칙만 둔다.

## 층

```text
원시 토큰   blue-500, space-4 …            {토큰 파일 경로}
   ↓
의미 토큰   primary, text-subtle, status-error-bg …   화면 코드는 이 층만 쓴다
   ↓
부품        버튼 · 표 · 입력 · 배지 …       {부품 라이브러리 · 감싼 부품 경로}
   ↓
패턴        목록-상세 · 필터 · 일괄 처리 …  {패턴 코드 경로} — 아래 표
   ↓
화면        docs/SCREENS.md 에서 패턴을 고른다
```

- 테마 차이(제품별 주색 · 밀도)는 의미 토큰 값만 바꾼다. 화면 코드는 그대로다.
- 부품 API 어휘를 통일한다: `color`(의미) · `variant`(강조 4단: bold · moderate · subtle · minimal) · `size`.

## 패턴

패턴 하나 = 코드 하나 + `templates/PATTERN.md` 로 쓴 정의 하나. 화면을 만들기 전에 필요한 패턴이 있는지 먼저 본다.

| 패턴 | 쓰는 곳 | 코드 | 정의 |
|---|---|---|---|
| {list-detail} | {목록에서 한 건을 골라 옆 서랍에서 본다} | | |
| {filter-bar} | | | |
| {bulk-action} | | | |

## 모든 화면의 상태 5개

패턴 코드가 기본 모양을 가진다. 화면은 문구만 바꾼다.

| 상태 | 보여 주는 것 | 금지 |
|---|---|---|
| 데이터 없음 | 왜 없는지 + 다음 행동 하나 | 빈 표만 띄우기 |
| 불러오는 중 | 자리 표시(skeleton) | 화면 전체 스피너 |
| 실패 | 무엇이 실패했는지 + 다시 시도 | 0 · 빈칸으로 보이기 |
| 권한 없음 | 숨기거나 「권한 없음」 | 눌렀을 때 오류 |
| 미측정 | 「미측정」 · 「미확인」 | **0 으로 보이기** |

## 하지 않는 것

| 금지 | 이유 |
|---|---|
| 토큰 밖의 색 · 간격 · 글자 · 반경 | 화면마다 어긋난다 |
| 부품마다 스타일 덮어쓰기 | 테마가 안 먹는다 |
| 유리 효과 · 글자 그라데이션 · 네온 그림자 · 배경 블러 원 | 업무 도구에 장식은 소음 |
| 모든 카드에 같은 큰 둥근 모서리 | 템플릿처럼 보인다 |
| 아이콘을 둥근 배경 상자로 감싸기 | 장식 |

# 5. CLAUDE.md 운영

> **목적:** `CLAUDE.md`를 한 번 쓰고 잊지 않고, **코드처럼 커밋·리뷰·점검**하는 방법을 정합니다.
> 근거: 강의 5-1(CLAUDE.md를 팀 자산으로 쓰기)과 Anthropic 공식 플러그인 `claude-md-management`의 1차 출처. 강의 내용 중 1차 출처로 확인되지 않은 것은 아래에 **미확인**으로 표시했습니다.

## 1. 어디에 무엇을 쓰는가

| 위치 | 담는 것 |
|---|---|
| 전역 `~/.claude/CLAUDE.md` | 내 개인 선호, 모든 프로젝트에 항상 적용할 행동 지침 |
| 프로젝트 루트 `CLAUDE.md` | 팀 컨벤션, 아키텍처 요약, AI가 자주 틀리는 것 |
| 하위 디렉터리 `CLAUDE.md` | 그 폴더(서비스·모듈)에서만 맞는 규칙 |

- **각 층에는 그 층에서만 의미 있는 정보만** 둡니다. 위 층에 있는 내용을 아래에 복사하지 않습니다.
- 1차 출처(improver)는 5종을 구분합니다: 루트, 개인용 `.claude.local.md`(gitignore, 공유 안 함), 전역, 패키지별, 하위. 강의의 3층에는 **`.claude.local.md`(로컬 오버라이드)가 빠져 있습니다.** 개인 메모는 거기에 둡니다.
- 층이 충돌할 때 "하위가 이긴다"는 강의 설명이지만 1차 출처에서 **미확인**입니다. 충돌 자체를 만들지 않는 쪽이 안전합니다.
- Karpathy 4지침(생각 먼저·단순함·외과적 수정·목표 중심 실행)은 **전역 `CLAUDE.md`**에 둡니다(항상 로드돼야 하므로, 프로젝트마다 복사하지 않음).

## 2. 운영 원칙 3가지

1. 루트 `CLAUDE.md`는 **커밋**합니다(개인 것은 `.claude.local.md`).
2. 변경은 **PR로만** 합니다. main 직접 수정 금지.
3. **주기적으로 점검**하고 책임자를 정합니다.

결정값(이 틀의 기준):
- 길이는 **200줄 이하** 권장. 넘기면 `docs/`로 링크하고 낡은 항목을 지웁니다. (플러그인의 평가 기준에는 줄 수 상한이 없고 "간결함"만 있습니다. 200줄은 이 틀이 정한 값입니다.)
- 점검 주기는 **2주마다 수동 실행**(1인 개발 기준). 팀이 커지면 조정합니다.

## 3. 언제 무엇을 하는가

| 시점 | 행동 |
|---|---|
| PR 올릴 때 | PR 양식의 "CLAUDE.md 업데이트 필요?"를 확인하고, 필요하면 **같은 PR**에 포함 |
| 2주마다 | `claude-md-improver` 수동 실행 → 리포트 확인 → 고칠 것은 PR로 |
| 세션 종료 | 힘든 세션·AI가 틀린 세션이었다면 `/revise-claude-md` 한 번 |
| 새 멤버 첫날 | clone 후 improver 1회 → 전역과 프로젝트 `CLAUDE.md` 충돌 점검 → 첫 PR로 개선 제안 |

강사의 운영 예시(이 틀은 채택하지 않음, 플러그인 기능 아님·**미확인**): cron/GitHub Action으로 주기 실행해 Slack·Discord로 리포트, 컨벤션만 바뀌고 `CLAUDE.md`는 안 바뀐 PR에 bot이 코멘트(drift 감지). 필요해지면 그때 도입합니다.

## 4. 점검 도구 사용법 (`claude-md-management`)

| | `claude-md-improver` (스킬) | `/revise-claude-md` (커맨드) |
|---|---|---|
| 비유 | 건강검진 | 회고 |
| 시점 | 코드가 바뀐 뒤 정기 점검 | 세션 종료 |
| 동작 | 모든 `CLAUDE.md` 탐색 → 6기준 100점 채점 → 리포트 → **내 승인 후** 수정 | 세션에서 빠졌던 맥락 정리 → diff 제시 → **내 승인 후** 수정 |

- improver는 스킬이므로 "CLAUDE.md 점검해줘"처럼 요청하면 호출됩니다. 수정은 리포트를 본 뒤 승인한 항목만 적용합니다.
- 채점 기준 6개: 명령·워크플로우 20, 아키텍처 명확성 20, 비자명한 패턴 15, 간결함 15, 최신성 15, 실행 가능성 15. 등급은 A~D, F.
- 설치 명령(`/plugin install ...`)과 `/claude-md` 명령 노출은 강의에만 나오고 1차 출처에서 **미확인**입니다. 설치는 [00번 가이드](00-new-pc-setup.md)의 플러그인 절차를 따릅니다.
- 같은 실수를 AI가 3번 했다면 `CLAUDE.md`에 규칙 한 줄([4번 가이드](4-review-and-done.md) 6장).

# C1. 미측정을 0 으로 다루지 않는다

> 예시 concern 이다. 규칙 하나를 어떻게 쓰는지 보여 준다. 프로젝트에 맞지 않으면 지운다.

## 왜
수집이 안 된 날의 광고비를 0 으로 넣으면 이익이 부풀고, 아무도 틀린 줄 모른다. 「없음」과 「0」은 다른 사실이다.

## MUST
- C1-1. 외부에서 값을 못 받았으면 `null`(또는 미측정 타입)로 둔다.
- C1-2. 화면은 `null` 을 「미측정」으로 보인다.
- C1-3. 분모가 0 이거나 `null` 이면 비율 · 평균을 계산하지 않고 「—」로 보인다.

## MUST NOT
- C1-4. `?? 0` · `|| 0` · `COALESCE(x, 0)` 으로 값이 없는 것을 0 으로 바꾸지 않는다. 진짜 0 이 정의된 필드만 예외이며, 그때는 그 줄에 까닭을 주석으로 남긴다.

## 판정
- 기계: `INDEX.yaml` 의 patterns 가 걸린 줄을 찾아, 예외 주석이 없으면 위반.
- 사람: 새 지표 · 합계를 만들 때 「값이 없는 날」 데이터로 화면을 한 번 본다.
